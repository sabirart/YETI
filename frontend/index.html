YETI

YouTube Video Downloader

Paste URL, select quality, add to queue.
Redownload, Remove, or Open folder.

Queue is temporary, clears on refresh.

Browser Extension

Download with one click directly from YouTube.

Installation Guide

  1. Download & extract the extension folder
  2. Go to chrome://extensions/ (Chrome) or about:addons (Firefox)
  3. Enable Developer Mode
  4. Click "Load unpacked" and select the folder

How to Use YETI

1

Paste a YouTube URL

Copy any YouTube video URL and paste it into the input field at the top.

2

Select Quality

Choose your preferred video quality from the dropdown menu (144p to 4K) or select "audio" for MP3.

3

Add to Queue

Click the "Download" button or press Enter to add the video to your download queue.

4

Manage Downloads

Use the action buttons to redownload, open the folder, or remove items from the queue.

Settings

Theme Toggle between dark and light mode
Downloads Folder Open the downloads directory
Clear Queue Remove all items from the download queue
