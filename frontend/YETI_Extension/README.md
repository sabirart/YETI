# YETI Browser Extension

One-click YouTube downloader for YETI.

## Installation

### Chrome / Edge / Brave
1. Open `chrome://extensions/`
2. Enable "Developer mode" (toggle in top right)
3. Click "Load unpacked"
4. Select this folder

### Firefox
1. Open `about:addons`
2. Click the gear icon ⚙️
3. Select "Install Add-on From File"
4. Select the extension .xpi file

## Usage
1. Make sure YETI backend is running (`npm start` in the backend folder)
2. Navigate to any YouTube video
3. Click the "YETI Download" button on the video player
4. The video is added to your queue

## Features
- One-click download from YouTube
- Works with YETI app
- Customizable quality
- Dark theme support
